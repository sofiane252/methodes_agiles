# Methodes Agiles

## Installation du projet

Pour installer et exécuter ce projet, suivez les étapes suivantes :

1. **Téléchargement des fichiers**
   - Téléchargez le fichier ZIP du projet depuis le dépôt GitHub.
   - Téléchargez l'archive du projet fournie par le professeur sur Moodle.

2. **Ouverture du projet dans Eclipse**
   - Décompressez l'archive Moodle et ouvrez le projet dans Eclipse afin de faciliter l'installation.

3. **Remplacement du dossier `src/`**
   - Remplacez le dossier `src/` de l'archive Moodle par celui du ZIP provenant du GitHub.

4. **Ajout du connecteur MySQL**
   - Placez le fichier `mysql-connector-j-9.2.0.jar` dans le dossier `lib` du projet.

5. **Configuration de la base de données**
   - Connectez-vous à une base de données MySQL.
   - Exécutez le fichier `foot.sql` pour créer la base de données et ses tables.

6. **Configuration de la connexion à la base de données**
   - Dans les fichiers `*DAO.java` situés dans le dossier `src/`, renseignez les informations de connexion à la base de données (URL, utilisateur, mot de passe).

7. **Exécution du projet**
   - Ouvrez le fichier `GestionFC.java` dans Eclipse.
   - Cliquez sur le bouton **Run** (triangle vert) pour exécuter l'application.

Votre projet est maintenant prêt à être utilisé !
